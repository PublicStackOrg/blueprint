# Migrating a Public Service from blueprint v0.2.0 to v0.3.0

`publicstack upgrade --to 0.3.0` is still a stub command. Until it lands,
follow this guide manually for any Public Service generated from blueprint
v0.2.0. The sections are independent — apply only the ones relevant to
your Public Service.

## What changed in v0.3.0

Phase 5 of `blueprint/docs/PLAN.md`:

- Shipped the **compliance suite** (`publicstack-compliance`) at
  `blueprint/compliance/`. Six checks: `data_export`, `contract_compat`,
  `grid_integration`, `security`, `observability`, `accessibility`.
- Bumped the template to a **compliant-by-default** baseline so a freshly
  generated PS exits 0 on `publicstack-compliance run`.
- `publicstack lint` is now a thin subprocess wrapper around
  `publicstack-compliance run`.

## Migration steps

### 1. Add the new dependencies in `services/api/pyproject.toml`

```diff
 [tool.poetry.dependencies]
 python = "^3.13"
 fastapi = "^0.115.0"
 uvicorn = { version = "^0.32.0", extras = ["standard"] }
 pydantic = "^2.10.0"
 pydantic-settings = "^2.7.0"
 prometheus-fastapi-instrumentator = "^7.0.0"
+opentelemetry-sdk = "^1.27.0"
+opentelemetry-instrumentation-fastapi = "^0.48b0"
+opentelemetry-exporter-otlp = "^1.27.0"
+python-json-logger = "^2.0.7"
```

Then `cd services/api && poetry lock && poetry install`.

### 2. Wire structured logging + OpenTelemetry + middleware in `main.py`

Add (or merge in) these imports:

```python
from fastapi.middleware.httpsredirect import HTTPSRedirectMiddleware
from opentelemetry import trace
from opentelemetry.instrumentation.fastapi import FastAPIInstrumentor
from pythonjsonlogger import jsonlogger
from starlette.middleware.base import BaseHTTPMiddleware
```

Replace `logging.basicConfig(...)` with a JsonFormatter:

```python
def _configure_logging(level: str) -> None:
    handler = logging.StreamHandler()
    handler.setFormatter(jsonlogger.JsonFormatter(
        "%(asctime)s %(levelname)s %(name)s %(message)s"
    ))
    root = logging.getLogger()
    root.handlers = [handler]
    root.setLevel(level.upper())
```

Add a CSP middleware:

```python
class CSPMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        response = await call_next(request)
        response.headers.setdefault(
            "Content-Security-Policy", "default-src 'self'"
        )
        return response

app.add_middleware(CSPMiddleware)
if settings.environment != "local":
    app.add_middleware(HTTPSRedirectMiddleware)
```

Wire OpenTelemetry instrumentation:

```python
FastAPIInstrumentor().instrument_app(app)
```

Update the unhandled-exception handler `extra=` to include
`request_id`, `path`, `trace_id`, `service`. See the upstream
`blueprint/template/{{…}}/services/api/api/main.py` for the full shape.

### 3. Add `environment` to `APISettings`

```diff
 class APISettings(Settings):
     api_host: str = Field(default="0.0.0.0")
     api_port: int = Field(default=8000)
+    environment: Literal["local", "staging", "prod"] = Field(default="local")
```

### 4. Add the `/export/items` endpoint and test

Create `services/api/api/routers/v1/export_router.py` with a NDJSON
streaming `GET /export/items` route, and `services/api/tests/test_export.py`
with an integration test mentioning `items`. Mount it in `v1_router.py`:

```diff
+from api.routers.v1.export_router import router as export_router
 v1_router.include_router(items_router, prefix="/items", tags=["items"])
+v1_router.include_router(export_router, tags=["export"])
```

### 5. Rename `get_storage_adapter` → `get_document_storage_adapter`

In `services/api/api/dependencies.py`, rename the storage factory:

```diff
-def get_storage_adapter(
+def get_document_storage_adapter(
```

Update any callers; the compliance suite's `grid_integration` check
expects `get_document_storage_adapter` to align with the Grid service
name `document_storage`.

### 6. Suppress OpenTelemetry's default exporter in tests

```python
# services/api/tests/conftest.py
import os
os.environ.setdefault("OTEL_SDK_DISABLED", "true")
```

### 7. Bump `BLUEPRINT_VERSION`

```bash
echo 0.3.0 > BLUEPRINT_VERSION
```

### 8. Run the compliance suite

```bash
pipx install <repo>/blueprint/compliance
publicstack-compliance run
```

Expect: green. If you see findings, address them per the rule's
suggestion line.

## Verifying

- `cat BLUEPRINT_VERSION` prints `0.3.0`
- `docker compose up` brings the stack up green (after `poetry install`)
- `pytest services/api/tests/` passes
- `publicstack-compliance run` exits 0

## Reverting

This guide does **not** include a downgrade path. Revert via git as
you'd revert any other patch: branch your in-progress work, check out
your last v0.2.0 commit, restart the dev loop.
